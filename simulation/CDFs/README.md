# Proposed TII Detector CDF Reproduction Package

This package contains the MATLAB code, saved detector-statistic samples, and three empirical CDF figures for `M = 16, 128, 256` at `SNR = 10 dB`.

## Folder contents

- `code/plot_Proposed_TII_D_CDF_M.m`: generates the detector-statistic samples, saves the data, and plots all three CDF figures.
- `code/PDF2.m`: local MATLAB dependency.
- `data/Proposed_TII_D_CDF_M.mat`: saved detector-statistic samples and experiment parameters.
- `results/`: MATLAB FIG, vector PDF, and PNG outputs for each antenna number.

## Results

- `CDF_Proposed_TII_D_M16.*`
- `CDF_Proposed_TII_D_M128.*`
- `CDF_Proposed_TII_D_M256.*`

The source files, data, and result files are copied without modification.
